# Provenance

This is an original, AI-assisted reference implementation created for a public technical portfolio. Its code, documentation, interface styling, test cases, and fixtures were written for this repository. No existing product implementation, private project code, customer material, confidential schema, credential, or production record was used.

All tenant names, principal names, item identifiers, channel identifiers, inventory quantities, notification text, timestamps used for expiry scenarios, and scenario outcomes are synthetic. Similarity to a real system is incidental.

The implementation uses Python's standard library at runtime. The optional package build uses setuptools; CI uses the named upstream GitHub Actions. The HTML uses system fonts, inline original CSS, and inline JavaScript. It includes no downloaded design assets or remote dependencies.

The committed `docs/demo.html` and `docs/demo.json` are generated evidence from this repository's offline simulator. They demonstrate tested local behavior only. No external tool service receives a request, no real notification is delivered, and no real inventory is modified. Runtime signing keys and live approval tokens are intentionally absent from those artifacts.

The project is not a certification, independent security audit, production deployment, or comprehensive defense against malicious model output. Its design and limitations are documented for inspection and adaptation.
